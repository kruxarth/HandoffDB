Every agent starts cold. Bearings hands it what earlier agents already worked out.

Each agent run is recorded in self-hosted HydraDB as structure, straight from its tool calls: what it opened, at which lines, which tests it found, what it concluded. No model call. The next agent, on the same task or a different one near the same code, gets a small pack from a few graph traversals instead of re-exploring or reading a pile of handoff notes.

What we learned first

Bearings began as a learned "where to start" pack. Retrieval beat keyword search, but live agents saved nothing: they open the right file in their first step or two anyway, and 93–96% of tokens are spent afterwards. That is why it was rebuilt around handoffs. The original results follow.
