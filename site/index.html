Every coding agent starts from zero

        

          
Over nine tenths of an agent's tokens go to reading after it has already opened the right file: the neighbouring code, the tests, the docs.

          
An earlier agent on the same repository has often read exactly that. HandoffDB keeps what it read and hands it to the next one.

A graph walk finds the agent’s files

          
A few algo.MSpaths traversals go from the task's words to earlier runs and their files.

          

            

              

                

                  CYpack.cypher
                  
                

                
MATCH (t:HTerm)-[:ABOUT]->(r:HRun)
WHERE t.word IN $words
MATCH (r)-[x:READ]->(f:HFile)
OPTIONAL MATCH
  (r)-[:CONCLUDED]->(f)
RETURN f.path, x.lines,
  count(r) AS runs

Install HandoffDB with two hooks

          
Clone it next to HydraDB, start the database, then paste the printed hooks into your repository's Claude Code settings.

          
    
            
  • Stop records the finished session from its transcript
    • 
            
  • UserPromptSubmit adds the pack to the next prompt
    • 
            
  • Linux or macOS with Docker, uv and git; the first HydraDB build takes about 15 minutes
    • 
          

          Read the README on GitHub
        

        

          

            
Terminal

            

              
1Clone and start HydraDB


git clone https://github.com/hydra-db/hydradb.git
git clone https://github.com/kruxarth/HandoffDB.git handoffdb
cd handoffdb && uv sync
scripts/start_hydradb.sh

            

            

              
2Print the hooks for your repository


uv run handoffdb --team myteam --repo myrepo \
  handoff-hooks-config

"hooks": { "Stop": …, "UserPromptSubmit": … }

            

          

        

      

    

  


  

    

      

        

          
Questions

          
The measurement, the limits and what it runs on.

          Read the raw results
          

            
            
            
            
            
          

          
Works with Claude Code, Docker, Git, Python and uv. Measured on Django.

        

        

          
Does the handoff pack save tokens on a new issue?
No. On 102 new issues the pack cost about the same as a cold start, at the same 68% success. The gain is on repeat work.

          
Does recording an agent run call a model?
No. The recorder reads tool calls from the transcript and finds names with regular expressions and git grep.

          
How big does a pack get after 301 runs?
About 334 tokens at the median after 301 runs. Markdown handoff notes over the same runs reached 146,325 tokens.

          
Where does HydraDB keep the graph?
In HydraDB, one graph per repository. Team and repo map to HydraDB tenant and subtenant scopes, so every agent on the team shares it.

          
Which model and benchmark did the agents run on?
DeepSeek V4.1 Flash through OpenCode, sandboxed, on real SWE-bench Django issues, checked in code and pre-registered.
