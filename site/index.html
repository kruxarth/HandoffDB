HandoffDB: handoffs between coding agents, as a graph on HydraDB.

Every coding agent starts from zero. HandoffDB records each finished agent run as a graph, so the next agent starts where the last one left off.

The problem

Finding the right file is the cheap part.

Over nine tenths of an agent's tokens are spent after it has already opened the right file.

before: finding the file0% after it was already open
Where the tokens after that go
neighbouring source code21%
tests and docs26%
re-reading the fix file23%
repo-wide search18%
median over 40 issues, agents without a pack · results/level2_decompose.txt

That work is exactly what an earlier agent on the same repository has often already done. So HandoffDB records it, and hands it on.

How it works · write

A finished run becomes a few nodes.

From the run's tool calls, with no model call, HandoffDB records the files it opened (with line ranges), the tests and docs it found, and the file it concluded the fix belongs in.

On brand-new issues the pack costs the same as starting cold (median per-issue ratio 1.01) at the same success; the notes cost about a third more. Against the notes the pack used fewer tokens, but its success was 1 point lower, so by the pre-registered rule no saving is claimed. On the same issue, a single note written for exactly that issue is the cheapest; the pack is the one that raises success.

    
Measured with DeepSeek V4.1 Flash through OpenCode, sandboxed, on real SWE-bench Django issues, success checked in code. Pre-registered in bench/handoff_prereg.md. Brackets are 95% bootstrap intervals. Retrieval packs: median 334 tokens; packs given to live agents in the different-issue run: median 390.

Use it

  
Two Claude Code hooks. The graph fills itself.

  
Requirements: Linux or macOS, Docker, uv, git. The first HydraDB build takes about 15 minutes.

  

    
1

      
# clone HydraDB next to this repo, then HandoffDB
git clone https://github.com/hydra-db/hydradb.git
git clone https://github.com/kruxarth/HandoffDB.git handoffdb && cd handoffdb
uv sync
scripts/start_hydradb.sh   # builds and starts HydraDB

    
2

      
uv run handoffdb --team myteam --repo myrepo handoff-hooks-config

    
3

      
Paste the printed hooks block into your repository's .claude/settings.json.
        
Stop records the finished session from its transcript
UserPromptSubmit injects the pack into the next prompt

      

  

  
By hand: handoffdb handoff-record <transcript.jsonl> "<task>" records a session, handoffdb handoff-pack "<task>" prints the pack. Team and repo map to HydraDB tenant and subtenant scopes: one graph per repository, shared by every agent on the team.
