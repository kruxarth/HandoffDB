Bearings

A learned context layer for coding agents, stored as a graph in self-hosted HydraDB. Every number below is generated from the result files in this repository.

Try a task

Paste an issue, or pick a SWE-bench task from after the graph's cutoff. The suggestions come from one weighted path query against HydraDB; each line under a file is the graph path that justifies it.

Level 1: Learning from the task stream only (a team starting from an empty graph)

hit@5 = the real fix touched at least one of the 5 suggested files. Rolling mean over 100 tasks; each task is answered before it is learned.

All result tables (RESULTS.md)
